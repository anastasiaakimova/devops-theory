# Docker commands

|    |      | |
|----|----|---|
|`docker build` | создание образа | `docker build -t <image_name>:<tag> <path_to_dockerfile>` <br> присваивает имя и тег создаваемому образу|
|`docker images` | просмотр локальных образов | |
| `docker pull` |загрузка образа из Docker Hub |`docker pull <image_name>:<tag>` |
| `docker push` | отправка образа в репозиторий | `docker push <image_name>:<tag>` |
| `docker tag` | создание тега для образа | `docker tag <existing_image> <new_image_name>:<tag>` <br> Эта команда используется для присвоения нового тега уже существующему образу. <br> Это может быть полезно для версионирования или для подготовки образа к загрузке в репозиторий.|
|`docker run nginx`| запускается контейнер с NGINX | |
| `docker ps`| Cписок запущенных контейнеров | |
| `docker rmi` | удаление образа | `docker rmi <image_id_or_name>` <br> Эта команда удаляет один или несколько образов из вашей локальной системы |
|`docker exec -it <container_id> bash` | Зайти внутрь контейнера как в систему | Ты попадаешь внутрь, видишь своё root окружение — как будто это отдельная ОС, <br> хотя на самом деле ты всё ещё внутри хост-системы.|
| `docker history` | просмотр истории образа |`docker history <image_id_or_name>` <br> Команда позволяет просмотреть историю слоев образа. <br> Это полезно для анализа, какие шаги были выполнены при создании образа |
| `docker inspect` | подробная информация о образе |`docker inspect <image_id_or_name>` <br> Команда выводит полную информацию о Docker-образе в формате JSON, <br> включая его метаданные, слои, настройки и т. д. |
|`docker stats` | мониторинг ресурсов контейнера |`docker stats <container_id_or_name> `<br> Если тебе нужно отслеживать использование ресурсов контейнера (например, CPU, память, сеть)|
|`docker top <container_id_or_name>` |процессы в контейнере| Эта команда покажет список процессов, работающих внутри контейнера, а также их ID, использование CPU и памяти |
|`docker logs <container_id_or_name>`|  журналы контейнера |Она покажет все сообщения, которые были записаны в стандартный вывод или стандартную ошибку контейнера. |
|`docker diff <container_id_or_name>`| изменения в контейнере | Позволяет увидеть изменения, которые были сделаны в файловой системе контейнера с момента его запуска. <br> Она покажет, какие файлы были добавлены, изменены или удалены.|
|`docker info` | общая информация о Docker |Эта команда не предоставляет информации о конкретном контейнере, <br> но она может быть полезной для получения общей информации о Docker, <br> например, статусе демона Docker, количестве контейнеров и образов.|
|`docker save` | экспорт образа в файл |`docker save -o <output_file>.tar <image_name>:<tag>` <br> Команда позволяет сохранить образ в архивный файл <br> (например, для передачи его на другой хост или для бэкапа).|
| ` docker load` | импорт образа из файла | `docker load -i <input_file>.tar` <br> Команда используется для загрузки Docker-образа из файла, <br> ранее сохраненного с помощью `docker save`|
